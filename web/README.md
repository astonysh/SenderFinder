# 网页版（web/）

纯静态单页应用：`index.html`、`app.js`、`styles.css`、`assets/`。无需构建、无第三方依赖、可离线使用。

## 打开方式

1. **由服务器提供（推荐）**：启动服务器（`npm start`）后访问 `http://127.0.0.1:3390/`。
   页面与 API 同源，「设置 → 服务器地址」留空即可。
2. **直接打开本地文件（开发用）**：双击 `web/index.html`。此时没有“同源”，
   页面默认连接 `http://127.0.0.1:3390`，也可在「设置 → 服务器地址」中修改。
   注意：服务器的 CORS 目前只允许 `chrome-extension://*`，从 `file://` 打开时浏览器会拦截请求，
   页面会显示「无法连接服务器」。需要服务器额外允许该来源，或直接使用方式 1。

`app.js` 是普通脚本（非 ES module），因为浏览器不允许在 `file://` 下加载模块脚本。

## 访问令牌

- 除 `/api/health` 外，所有请求都带 `Authorization: Bearer <token>`。
- 令牌即服务器 `.env` 中的 `APP_TOKEN`，首次打开时在「连接服务器」对话框中输入一次。
- 令牌保存在本浏览器的 `localStorage`，键名 `el.token`；服务器地址保存在 `el.baseUrl`（空 = 同源）；主题保存在 `el.theme`。
- 保存后页面只显示掩码（`••••••••` + 末 4 位），不会输出到控制台或日志。
- 任一请求返回 401 时会重新弹出令牌输入框。在「设置」中可以「清除令牌」。

## 页面

- **查询**：单个邮箱查询，可选姓名、邮件签名（免费识别 LinkedIn 链接）、公司域名、单次费用上限、强制重新查询。
- **批量**：每行 `email`、`email, 姓名` 或 `姓名 <email>`，单次最多 50 条；每 5 条调用一次 `/api/lookup/batch` 以显示进度；可导出 CSV（UTF-8 BOM，Excel 可直接打开）。
- **历史**：分页、搜索、状态筛选；点击行查看详情；「重新查询」会先删除缓存再查询。
- **用量**：今日 / 本月 / 累计、今日预算、近 30 天柱状图（内联 SVG，支持方向键逐日查看）、各数据源统计。
- **设置**：服务器地址、令牌、测试连接（`/api/health` + `/api/steps`）。

小技巧：`#/lookup?email=jane@acme.com&name=Jane%20Doe` 会预填查询表单（不会自动查询，避免产生费用）。
