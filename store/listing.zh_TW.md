# Browser store listing (zh_TW)

## Description

在 LinkedIn 上找到寄件者。讓聯繫不止於郵件。

開啟郵件，找到寄件者的 LinkedIn 個人檔案。與對方建立聯繫，讓這份關係延續下去。SenderFinder 在 Gmail 或 Outlook 網頁版的側邊面板顯示姓名、職稱、公司、地點、照片及個人檔案連結（視資料是否可用）。同一郵件串的其他參與者可點擊查詢。

查詢與費用
先在本機掃描郵件簽名中的 LinkedIn 連結，找到時免費。再依設定順序呼叫你選擇的供應商，找到相符資料即停止。貼上 treg、Monid 或 Firecrawl 的個人金鑰即可開始；供應商服務可能另外收費。Firecrawl 可依姓名與公司搜尋 LinkedIn 公開頁面，並提供 Data Legion 備援。你可設定單次、每日及自動查詢上限。結果保留在本機快取，可在設定中管理。請先確認資料是否符合寄件者，再決定是否聯繫。

在 LinkedIn 建立聯繫
選用功能可透過你自己的 LinkedIn 登入工作階段讀取關係程度、照片及關聯公司連結。建立聯繫按鈕開啟對方檔案，邀請對話框出現後可點一次「Add a note」並填入你可編輯的範本。建立聯繫及傳送均由你自己操作；插件不會替你點擊這兩個按鈕。LinkedIn 存取權限可在設定中撤銷。

隱私與資料
不需 SenderFinder 帳號。查詢直接從你的瀏覽器傳送給所設定的供應商；欄位可包含電子郵件、姓名及公司網域。郵件內文只在本機掃描，不會儲存或傳送。金鑰、查詢記錄及快取保留在此瀏覽器；金鑰只傳送給對應供應商。可匯出或刪除資料，預設保留 90 天。匿名每日使用統計預設開啟，只含使用計數、版本、語言及隨機安裝 ID 等，不含郵件內容、身分資料或金鑰；設定中可預覽或關閉。

開放原始碼，AGPL-3.0。Gmail 為主要支援平台；Outlook 網頁版盡力支援。Monid 與 Firecrawl 註冊連結為推廣連結，符合條件的註冊或付費可能為維護者帶來佣金。SenderFinder 與 LinkedIn、Google、Microsoft 或資料供應商無隸屬關係。
