# Browser store listing (ja)

## Description

LinkedIn で送信者を見つけよう。メールを超えてつながろう。

メールを開いて送信者の LinkedIn プロフィールを見つけ、つながりを育てましょう。SenderFinder は Gmail や Outlook ウェブ版のサイドパネルに、取得できた氏名、役職、会社、所在地、写真、プロフィールへのリンクを表示します。スレッド内のほかの参加者もクリックで検索できます。連絡する前に、本人のプロフィールか確認してください。

検索と料金
まずメール本文を端末内で調べ、LinkedIn プロフィールのリンクを探します。この処理は無料です。その後、設定した順序でデータプロバイダーを照会し、一致するプロフィールが見つかれば停止します。treg、Monid、Firecrawl のいずれかの自分のキーで始められます。各社のサービスには別途料金がかかる場合があります。Firecrawl は氏名と会社から LinkedIn の公開ページをウェブ検索し、その後 Data Legion を代替手段として利用できます。検索ごと、1日ごと、自動検索の上限を設定可能。結果はブラウザ内にキャッシュされます。

LinkedIn でつながる
任意の許可を与えると、自分の LinkedIn ログインセッションでつながりの度合い、写真、関連する会社のリンクを取得できます。つながるボタンは相手のプロフィールを開きます。招待ダイアログでは「Add a note」を1回クリックし、編集可能なテンプレートを入力できます。「つながる」と「送信」は自分でクリックします。拡張機能がこれらのボタンを押すことはありません。権限は設定で取り消せます。

プライバシー
SenderFinder アカウントは不要です。検索対象のメールアドレス、氏名、会社ドメインなどは、ブラウザから設定済みプロバイダーに直接送信されます。メール本文は端末内でのみ解析され、保存や送信はしません。キー、履歴、キャッシュはブラウザ内に保持され、キーは対応するプロバイダーにのみ送られます。データはエクスポート・削除でき、既定の保持期間は90日です。匿名の日次利用統計は既定で有効で、利用件数、バージョン、言語、ランダムなインストール ID などを含みます。メール内容、人物を特定する情報、キーは含みません。設定で内容を確認したり無効にしたりできます。

オープンソース、AGPL-3.0。Gmail に対応し、Outlook ウェブ版は可能な範囲で対応します。Monid と Firecrawl の登録リンクは紹介リンクです。条件を満たす登録や支払いにより、開発者が紹介料を受け取る場合があります。SenderFinder は LinkedIn、Google、Microsoft、各データプロバイダーとは提携していません。
