# Browser store listing (ko)

## Description

LinkedIn에서 발신자를 찾으세요. 이메일을 넘어 연결하세요.

이메일을 열어 발신자의 LinkedIn 프로필을 찾고 오래 이어질 관계를 시작하세요. SenderFinder는 Gmail 또는 Outlook 웹의 측면 패널에 확인 가능한 이름, 직책, 회사, 위치, 사진과 프로필 링크를 표시합니다. 대화에 참여한 다른 사람도 클릭하여 조회할 수 있습니다. 연락하기 전에 올바른 프로필인지 확인하세요.

조회와 비용
먼저 이메일 본문에서 LinkedIn 프로필 링크를 기기 내에서 무료로 찾습니다. 이후 설정한 순서로 데이터 제공업체를 조회하며 일치하는 프로필을 찾으면 멈춥니다. treg, Monid 또는 Firecrawl의 개인 키 하나로 시작할 수 있습니다. 제공업체 서비스에는 별도 요금이 발생할 수 있습니다. Firecrawl은 이름과 회사로 LinkedIn 공개 페이지를 웹 검색한 뒤 Data Legion을 대체 수단으로 사용할 수 있습니다. 조회별, 일별 및 자동 조회 한도를 설정할 수 있으며 결과는 브라우저에 캐시됩니다.

LinkedIn에서 연결
선택적 권한을 허용하면 본인의 LinkedIn 로그인 세션으로 연결 관계, 사진 및 관련 회사 링크를 읽습니다. 연결 버튼은 상대의 프로필을 엽니다. 초대 대화상자에서 확장 프로그램이 «Add a note»를 한 번 클릭하고 수정 가능한 템플릿을 입력할 수 있습니다. 연결과 보내기 버튼은 사용자가 직접 누르며 확장 프로그램은 이 두 버튼을 누르지 않습니다. 설정에서 권한을 철회할 수 있습니다.

개인정보
SenderFinder 계정이 필요하지 않습니다. 조회 대상의 이메일, 이름, 회사 도메인 등의 정보는 브라우저에서 설정한 제공업체로 직접 전송됩니다. 이메일 본문은 기기 내에서만 분석하며 저장하거나 전송하지 않습니다. 키, 기록, 캐시는 브라우저에 보관되며 키는 해당 제공업체에만 전송됩니다. 데이터는 내보내거나 삭제할 수 있고 기본 보관 기간은 90일입니다. 익명 일일 사용 통계는 기본으로 켜져 있으며 사용 횟수, 버전, 언어 및 무작위 설치 ID 등을 포함합니다. 이메일 내용, 신원 정보 또는 키는 포함하지 않습니다. 설정에서 전송 내용을 확인하거나 끌 수 있습니다.

오픈 소스, AGPL-3.0. Gmail을 지원하며 Outlook 웹은 가능한 범위에서 지원합니다. Monid와 Firecrawl 가입 링크는 추천 링크로, 조건에 맞는 가입이나 결제 시 유지관리자에게 수수료가 지급될 수 있습니다. SenderFinder는 LinkedIn, Google, Microsoft 또는 데이터 제공업체와 제휴 관계가 없습니다.
