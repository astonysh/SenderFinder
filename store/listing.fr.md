# Browser store listing (fr)

## Description

Trouvez l’expéditeur sur LinkedIn. Créez des liens au-delà de votre boîte mail.

Ouvrez un e-mail pour trouver le profil LinkedIn de son expéditeur, puis établissez une relation qui dure. Dans Gmail ou Outlook sur le web, SenderFinder affiche dans un panneau latéral les informations disponibles : nom, poste, entreprise, lieu, photo et lien du profil. Les autres participants du fil peuvent être recherchés d’un clic. Vérifiez le résultat avant de contacter la personne.

RECHERCHE ET COÛTS
Le texte du message est d’abord analysé localement pour y trouver un lien LinkedIn, gratuitement. Les fournisseurs configurés sont ensuite interrogés dans l’ordre choisi, jusqu’à trouver un profil correspondant. Une clé personnelle de treg, Monid ou Firecrawl suffit pour commencer ; leurs services peuvent être payants. Firecrawl permet une recherche web publique sur LinkedIn par nom et entreprise, puis un recours à Data Legion. Fixez vos plafonds par recherche, par jour et pour les recherches automatiques. Les résultats sont mis en cache localement.

SE CONNECTER SUR LINKEDIN
Avec une autorisation facultative, SenderFinder utilise votre propre session LinkedIn pour lire le degré de relation, la photo et les liens d’entreprises associés. Le bouton de connexion ouvre le profil. Dans la fenêtre d’invitation, l’extension peut cliquer une fois sur « Add a note » et insérer votre modèle modifiable. Vous cliquez vous-même sur les boutons de connexion et d’envoi ; SenderFinder ne le fait jamais. L’accès peut être révoqué dans les paramètres.

CONFIDENTIALITÉ
Aucun compte SenderFinder requis. Les données de recherche, telles que l’adresse e-mail, le nom et le domaine de l’entreprise, sont envoyées directement de votre navigateur au fournisseur choisi. Le corps du message est analysé localement, sans stockage ni transmission. Clés, historique et cache restent dans le navigateur ; les clés sont envoyées uniquement à leur fournisseur. Vous pouvez exporter ou effacer les données ; la conservation par défaut est de 90 jours. Les statistiques d’utilisation quotidiennes anonymes sont activées par défaut : compteurs, version, langue et identifiant d’installation aléatoire, sans contenu des messages, données personnelles ni clés. Elles sont consultables et désactivables dans les paramètres.
