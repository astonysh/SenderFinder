Clearbit Connect is gone. Here is an open-source alternative.

SenderFinder shows who is emailing you, right inside Gmail. It is open source, runs on your own API keys and needs no account.

Coming to the Chrome Web Store How it works

What Clearbit Connect was

Clearbit Connect was a free extension for Gmail and Outlook. When you read an email, it showed information about the sender, such as their role and company.

After HubSpot acquired Clearbit, Clearbit Connect was discontinued. It stopped working on 30 April 2025.

What SenderFinder does

Open an email in Gmail. The browser's side panel shows that person's LinkedIn profile: name, headline, company, location and a link to the profile. Other people in the thread are listed below, and you can look them up with a click.

Outlook on the web is supported on a best-effort basis.

What is different

  • Open source. The code is on GitHub under the AGPL-3.0 license. You can read exactly what it does.
  • Your own keys. The extension calls data providers directly from your browser, using keys you paste into its settings. Supported: Monid and treg, with Firecrawl as an optional fallback.
  • No account. There is no signup and no server in the lookup path. The only thing sent to us is a daily anonymous usage count, which you can switch off.
  • No CRM lock-in. Results stay in your browser. You can export history as JSON or CSV and take it wherever you like.
  • Predictable cost. The cheapest source is tried first, and the chain stops at the first match. A per-lookup cap and a daily cap keep spending in check. Results are cached, so an address is never paid for twice.

Honest limitations

  • You need a provider key. One key from Monid or treg is enough to start, but you have to create it yourself.
  • It isn't free per lookup. A successful lookup typically costs between $0.0005 and $0.03, usually well under a cent. Misses on most providers are free.
  • No Firefox yet. It runs in Chrome. Desktop mail apps such as Apple Mail and Outlook for desktop are not supported.
  • Results depend on provider coverage. Some people won't be found. When a provider's name doesn't match the name in the email, the result says "uncertain" and shows both.

Switching takes a few minutes

  1. Install the extension. Until the Chrome Web Store listing is live, install it from source.
  2. Create an API key at Monid or treg.
  3. Paste it into the extension's settings and open an email in Gmail.
