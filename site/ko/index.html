작동 방식

한 번만 설정하면 받은편지함을 읽습니다

확장 프로그램을 설치하고 제공업체 키 하나를 붙여 넣으면, 여는 메일마다 발신자가 누구인지 표시됩니다.

열어 본 메일을 읽습니다

발신자와 받는 사람, 참조에 있는 모든 사람입니다. 본문은 linkedin.com/in 링크를 찾기 위해서만 로컬에서 스캔합니다.

가장 저렴한 출처부터

무료 서명 스캔에서 유료 제공업체로 이어지는 연쇄 조회이며, 저렴한 순서입니다. 실패한 조회는 무료이고, 일치하면 연쇄가 멈춥니다.

키 하나면 충분합니다

가장 저렴한 조회는 treg, 가장 넓은 범위는 Monid입니다. 키 하나만 있어도 전체 흐름이 작동합니다.

스레드 전체

다른 발신자와 받는 사람, 참조가 패널에 나열되며, 각 사람은 직접 클릭할 때만 조회합니다.

LinkedIn에서 연결

패널이 프로필을 열고 메모를 미리 채웁니다. 연결과 보내기는 직접 누르며, 확장 프로그램이 대신 누르지는 않습니다.

캐시와 기록은 로컬에

결과는 브라우저의 IndexedDB에 90일 동안 보관되며, JSON 또는 CSV로 내보내고 한 번의 클릭으로 삭제할 수 있습니다.

개인정보

받은편지함은 사용자의 것입니다

조회는 브라우저에서 직접 고른 제공업체로 곧바로 전송됩니다. 기기에 남는 것, 밖으로 나가는 것, 익명 집계에 포함되는 것을 정확히 정리했습니다.

기기에 남는 것

  • 제공업체 키, 확장 프로그램 자체 스토리지에
  • 캐시와 기록, IndexedDB에(90일, 5,000개 항목)
  • 설정, 상한, 자동 조회 한도
  • 어떤 메일을 열었는지에 대한 정보는 브라우저를 벗어나지 않습니다

직접 고른 제공업체로 전송되는 것

  • 사용자의 키와 함께 전송되는, 조회하는 주소
  • 메일 헤더의 표시 이름
  • Apollo 단계에서 쓰는 회사 도메인
  • 해당 제공업체의 카탈로그 가격 조회 요청

익명 사용 집계

  • 기본적으로 켜져 있으며, 설정의 스위치 하나로 끕니다
  • 일일 합계: 횟수, 결과, 지출, 버전, 언어
  • 무작위 설치 ID이며, 집계를 끄면 삭제됩니다
  • 주소, 이름, 도메인, 키, 메시지 본문은 절대 포함되지 않습니다

숫자의 출처
  • 새 발신자 주소는 한 번 조회되고 캐시됩니다. 다시 나타난 발신자는 $0이므로 입력은 읽은 메일 수가 아니라 하루당 새 주소 수입니다.
  • 적중당 가격은 2026년 10월 25일 제공업체 카탈로그 가격입니다. BlitzAPI $0.0005, QuickEnrich $0.0048, Hunter $0.0049, Apollo $0.026입니다. 이 단계에서는 실패해도 무료입니다.
  • 단계별 적중률은 2026년 10월 25일 50개 주소 벤치마크에서 나왔습니다. 48 %는 BlitzAPI가 해결했고, 남은 것의 19 %를 다음 단계가, 그 나머지의 19 %를 그다음 단계가 해결했습니다. Apollo는 호출된 19개 주소 중 17개에 답했습니다.
  • 두 키를 쓰면 업무용 주소의 약 95 %를 찾고, 측정값은 50개 중 48개(96 %)입니다. treg만 쓰면 저렴한 두 단계만, Monid만 쓰면 Hunter와 Apollo가 실행됩니다.
  • 월 비용 = 하루당 새 주소 수 × (1 − 건너뛴 비율) × 30 × 주소당 비용. 무료 이메일 서명 스캔, 선택 단계인 Village와 ContactOut, Firecrawl은 포함되지 않습니다.
  • 영어권 세일즈·그로스 담당자를 대상으로 한 벤치마크 하나에서 나온 추정치입니다. 실제 받은편지함에서는 다를 수 있습니다.

질문

짧은 답변

더 자세한 내용은 설치 안내와 개인정보 처리방침에 있습니다.

무료인가요?

예. 확장 프로그램은 AGPL-3.0 라이선스로 공개된 무료 오픈 소스이며, 계정도 구독도 없습니다. 유료 조회는 선택 사항입니다. 직접 고른 데이터 제공업체가 직접 발급한 키로 조회 건당 청구하며, 설정한 상한 안에서 이루어집니다. 서명 스캔과 캐시는 무료입니다.

계정이 필요한가요?

가입은 필요하지 않습니다. 조회는 설정한 제공업체로 직접 전송되며, 익명 일일 사용 통계는 프로젝트의 통계 서비스로 전송되는데 설정의 스위치 하나로 끌 수 있습니다.

어떤 키를 받아야 하나요?

Monid 또는 treg의 키 하나면 시작할 수 있습니다. 둘 다, 그리고 원하면 Firecrawl까지 추가하면 연쇄 조회에서 시도할 곳이 늘어납니다. 설치 페이지에서 비교합니다.

비용은 어떻게 관리하나요?

조회당 상한(기본 $0.05)과 일일 상한(기본 $2)이 있습니다. 열어 본 메일의 발신자만 자동으로 조회되며, 여기에 설정한 하루 한도가 적용됩니다. 결과는 캐시되므로 같은 주소로 두 번 결제하지 않습니다. 계산기에서 특정 사용량의 비용을 볼 수 있습니다.

엉뚱한 사람이 나오면요?

제공업체가 준 이름이 메일 헤더의 표시 이름과 다르면 결과에 “불확실”이 표시되고 두 이름이 함께 나옵니다. 직접 판단할 수 있습니다.

gmail.com 발신자는 왜 조회하지 않나요?

개인 메일 도메인과 info@ 같은 역할 주소는 프로필과 일치하는 경우가 드물어서, 비용을 아끼기 위해 기본적으로 건너뜁니다. 패널의 버튼을 누르면 그래도 조회할 수 있습니다.
