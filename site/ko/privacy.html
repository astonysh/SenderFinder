개인정보 처리방침

최종 업데이트: 2026년 10월 25일

이 문서는 번역본이며, 내용이 다를 경우 영어 원문이 우선합니다.

SenderFinder는 열린 이메일의 발신자와 참여자를 읽고, 본문을 로컬에서 스캔해 LinkedIn 프로필 링크를 찾습니다. LinkedIn 기능을 켜면 사용자의 LinkedIn 세션으로 인맥 정도, 대기 중인 초대, 사진, 연결된 회사 링크를 읽습니다. Connect 도우미는 “Add a note”를 한 번 클릭하고 검토할 메모를 채웁니다. 조회 항목은 설정한 제공업체로 직접 전송됩니다. 익명 사용 통계는 기본적으로 켜져 있으며, 설정의 스위치 하나로 끕니다.

30초 요약

  • 조회는 브라우저에서 설정한 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다.
  • 키, 캐시, 기록은 이 기기의 확장 프로그램 스토리지와 브라우저 IndexedDB에 남습니다. 한 번의 클릭으로 내보내거나 지울 수 있습니다.
  • 제공업체는 조회하는 주소, 메일 헤더의 표시 이름, 회사 도메인을 받습니다. 그 밖에는 없습니다.
  • 메일 본문은 브라우저를 벗어나지 않습니다. 서명 스캔은 로컬에서 실행됩니다.
  • 사용 통계는 기본적으로 켜져 있습니다. 조회 횟수와 결과, 지출, 버전, 언어에 무작위 설치 ID를 더한 익명 일일 요약이 하루에 한 번 프로젝트의 통계 서비스로 전송됩니다. 설정의 스위치 하나를 끄면 전송이 중단되고 설치 ID가 삭제됩니다. 주소, 이름, 도메인, 프로필 항목, 키, 메시지 본문은 절대 포함되지 않습니다.
  • 사용할 제공업체와 조회 대상은 사용자가 선택합니다. 통계를 끄고 LinkedIn 권한을 취소하며 로컬 데이터를 내보내거나 삭제할 수 있습니다. 각 기능의 데이터 처리 방식은 아래 설명을 참고하세요.

SenderFinder를 운영하는 주체

SenderFinder는 오픈소스 Chrome 확장 프로그램입니다. 조회 요청은 브라우저에서 설정한 데이터 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다. 별도의 통계 서비스가 익명 일일 요약을 하나 받는데, 기본적으로 켜져 있고 설정 페이지에서 끌 수 있습니다. 통계의 데이터 관리자는 astonysh/SenderFinder 관리자인 Tony Li입니다. 개인정보 관련 요청은 tony@senderfinder.com으로 보내 주세요.

확장 프로그램이 읽고 보관하는 것

웹 Gmail 또는 웹 Outlook에서 확장 프로그램은 열린 메시지의 발신자와 참여자를 읽습니다. LinkedIn 프로필 URL, 예를 들어 서명에 있는 링크를 찾기 위해 메시지 본문을 로컬에서 스캔합니다. 본문은 저장되지 않고 전송되지도 않습니다. 조회 기록, 결과, 설정, 제공업체 키는 확장 프로그램이나 브라우저에 로컬로 저장됩니다. 캐시된 결과는 기본적으로 90일 후 만료되며 항목 수 상한은 5,000개입니다. 설정에서 내보내거나 삭제할 수 있습니다.

데이터 제공업체가 받는 것

조회가 실행되면 선택한 사람의 이메일 주소, 표시 이름, 회사 도메인이 해당 제공업체의 API 키를 사용해 직접 설정한 제공업체로 곧바로 전송됩니다. 일부 제공업체는 집계 서비스이며 요청을 자사가 나열한 하위 서비스로 전달할 수 있고, 이때는 해당 서비스의 약관과 개인정보 처리방침이 적용됩니다. SenderFinder는 조회 주소나 제공업체의 결과를 받지 않습니다. 제공업체가 반환한 업무용 프로필 항목은 로컬에 보관하고, 전화번호와 개인 이메일 주소는 버립니다.

익명 사용 통계

사용 통계는 기본적으로 켜져 있습니다. 확장 프로그램은 하루에 한 번 전날의 요약을 Cloudflare Worker로 보내고, Worker는 이를 Cloudflare D1에 저장합니다. 요약에는 날짜, 확장 프로그램 버전, 인터페이스 언어, 조회 총계와 결과, 제공업체 단계별 횟수, 메일 클라이언트별 합계, 반올림한 지출, 무작위 설치 ID가 포함됩니다. 이 ID는 사람이 아니라 설치를 식별합니다. 설정 페이지의 스위치 하나를 끄면 요약 전송이 중단되고 설치 ID와 미전송 데이터가 삭제되며, 옆의 미리보기 버튼은 전송될 내용을 그대로 보여 줍니다.

요약에는 이메일 주소, 이름, 회사 도메인, LinkedIn URL, 프로필 항목, 제공업체 키, 메시지 본문이 포함되지 않습니다. 설정에서 전송될 내용을 그대로 미리 볼 수 있습니다. 통계를 끄면 앞으로의 전송이 중단되고 로컬 설치 ID와 미전송 요약이 삭제됩니다. 이전에 받은 요약의 삭제를 요청하려면 미리보기에 표시되는 설치 ID와 함께 tony@senderfinder.com으로 연락하세요.

LinkedIn

LinkedIn 기능을 켜면 확장 프로그램은 처음 사용할 때 선택적인 linkedin.com 권한을 요청합니다. 이 권한은 설정에서 언제든 취소할 수 있고, 확장 프로그램이 직접 연 탭에만 적용됩니다. 이를 허용하면 확장 프로그램은 사용자의 LinkedIn 세션으로 읽고 있는 프로필의 인맥 정도, 대기 중인 초대, 프로필 사진, 연결된 회사 링크를 요청합니다. 인증 쿠키인 JSESSIONID는 이 요청의 CSRF 값으로 로컬에서 읽으며, 쿠키는 LinkedIn에만 전송되고 SenderFinder나 데이터 보강 제공업체에는 전송되지 않습니다. 결과는 기기에 캐시되고 어디에도 전송되지 않습니다. Connect를 선택하면 확장 프로그램이 선택한 프로필을 열고 초대 창에서 “Add a note”를 한 번 클릭해 편집 가능한 템플릿을 채웁니다. Connect나 Send를 클릭하지는 않습니다.

사용자의 선택과 Chrome Web Store 정책

어떤 데이터 제공업체와 API 키를 설정할지, 누구를 조회할지는 사용자가 정합니다. 키를 삭제하고, 통계를 끄고, LinkedIn 액세스를 취소하고, 로컬 기록을 내보내거나 지우고, 확장 프로그램을 제거할 수 있습니다. SenderFinder는 사용자가 요청한 조회를 표시하고 수행하는 데에만 메일함 데이터를 사용합니다. 메일 본문 텍스트는 LinkedIn 프로필 링크를 찾기 위해서만 로컬에서 처리되며, 광고에 사용되지 않고 SenderFinder나 제공업체로 전송되지 않습니다.

쿠키와 로컬 스토리지

이 절은 확장 프로그램이 아니라 SenderFinder 웹사이트를 설명합니다. 확장 프로그램은 익명 일일 사용 통계 요약을 하나 보내며, 기본적으로 켜져 있고 확장 프로그램 설정에서 끌 수 있습니다. 웹사이트 자체는 아래에 설명된 브라우저 로컬 저장소를 사용합니다.

현재 이 웹사이트는 쿠키를 설정하지 않습니다. 브라우저의 localStorage에는 두 개의 항목이 사용되며, 둘 다 사용자가 요청한 경우에만 쓰입니다. el-theme은 헤더에서 고른 라이트 또는 다크 선택을 기억하고, sf-notice는 페이지 하단의 안내를 닫았다는 사실을 기억합니다. 어느 것도 어디로도 전송되지 않으며, 브라우저에서 사이트 데이터를 지우면 둘 다 삭제됩니다.

웹사이트 분석. 이 사이트에 분석 도구가 추가되면 이 단락에서 도구 이름, 집계 항목, 거부 방법을 밝히고, 법에서 요구하는 경우 페이지 하단 안내에서 동의를 받습니다. 그때까지 이곳에서는 외부의 분석 스크립트, 폰트, 이미지를 전혀 불러오지 않습니다.

이 사이트는 Cloudflare Workers Static Assets에서 호스팅됩니다. Cloudflare는 페이지를 전달하고 서비스를 남용으로부터 보호하기 위해 IP 주소 같은 요청의 기술적 데이터를 자체 개인정보 약관에 따라 처리합니다.

이 사이트에서는 Cloudflare Web Analytics, Zaraz 및 이와 유사한 삽입 기능을 활성화하지 않았습니다. 이 점이 바뀌면 이 절도 함께 바뀝니다.

이 웹사이트와 연락처

이 웹사이트는 정적이며 쿠키나 분석 도구를 사용하지 않습니다. 질문이나 개인정보 관련 요청은 tony@senderfinder.com으로 연락하거나 GitHub에 이슈를 열어 주세요.
