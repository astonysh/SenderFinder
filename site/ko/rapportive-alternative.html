SenderFinder는 10개 언어로 제공됩니다. 확장 프로그램은 브라우저 언어를 따릅니다.

Rapportive는 사라졌습니다. 아이디어는 여전히 통합니다.

SenderFinder는 Rapportive의 단순한 부분을 되살립니다. Gmail에서 메일을 열면 누가 보냈는지 볼 수 있습니다. 오픈 소스, 직접 발급한 API 키, 계정 없음.

2분 만에 설치 작동 방식

Rapportive란 무엇이었나

Rapportive는 메일을 주고받는 상대의 LinkedIn 프로필을 메시지 옆에 보여 주는 Gmail 부가 기능이었습니다. LinkedIn이 2012년에 인수했고, 이후 서비스를 종료했습니다.

SenderFinder가 하는 일

Gmail에서 메일을 열면 브라우저 사이드 패널에 발신자의 이름, 한 줄 소개, 회사, 위치, LinkedIn 프로필 링크가 표시됩니다. 스레드의 다른 사람(다른 발신자, 받는 사람, 참조)은 아래에 나열되며 클릭할 때만 조회합니다. 메일 본문에는 발신자 옆에 작은 표시만 붙습니다.

웹 Outlook은 가능한 범위 내에서 지원합니다.

무엇이 다른가

  • 오픈 소스. AGPL-3.0 라이선스이며 코드는 GitHub에 있습니다. 어떤 회사도 임의로 끌 수 없습니다.
  • 직접 발급한 키. 프로필은 직접 선택한 데이터 제공업체에서 가져옵니다: Monid 또는 treg, 선택적 대체 수단으로 Firecrawl. 확장 프로그램은 브라우저에서 이들을 직접 호출합니다.
  • 가입 불필요. 조회는 브라우저에서 설정한 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다. 익명 일일 사용 통계는 기본적으로 켜져 있고 설정에서 끌 수 있습니다.
  • CRM에 묶이지 않습니다. 기록은 브라우저에 남습니다. 원할 때 언제든 JSON이나 CSV로 내보낼 수 있습니다.
  • 이름 확인. 제공업체가 준 이름이 메일의 표시 이름과 다르면 결과에 “불확실”이 표시되고 두 이름이 함께 나옵니다.

솔직한 한계

  • 제공업체 키가 필요합니다. Monid 또는 treg 키 하나면 시작할 수 있습니다.
  • 조회에는 약간의 비용이 듭니다. 조회 성공 시 보통 $0.0005에서 $0.03 사이이며, 대개 1센트를 크게 밑돕니다. 대부분의 제공업체는 실패해도 무료이고, 결과는 캐시되므로 같은 주소로 두 번 결제하는 일은 없습니다.
  • 지출에는 직접 정한 한도가 있습니다. 조회당 상한(기본 $0.05)과 일일 상한(기본 $2)이 적용됩니다. 열어 본 메일의 발신자만 자동으로 조회합니다.
  • Firefox는 아직 없습니다. Chrome에서 동작합니다. 데스크톱 메일 앱은 지원하지 않습니다.
  • 범위는 상황에 따라 다릅니다. 모든 사람을 찾지는 못하며, gmail.com 같은 개인 주소는 기본적으로 건너뜁니다. 버튼을 누르면 그래도 조회할 수 있습니다.

데이터가 가는 곳

Rapportive도 호스팅 서비스였습니다. 프로필 조회는 Rapportive 계정에 묶여 그 서버에서 실행되었습니다.

SenderFinder는 오픈소스 Chrome 확장 프로그램입니다. 조회 요청은 브라우저에서 설정한 데이터 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다. 별도의 통계 서비스가 익명 일일 요약을 하나 받는데, 기본적으로 켜져 있고 설정 페이지에서 끌 수 있습니다. 통계의 데이터 관리자는 astonysh/SenderFinder 관리자인 Tony Li입니다. 개인정보 관련 요청은 tony@senderfinder.com으로 보내 주세요.

개인정보 처리방침에 무엇이 전송되고, 무엇이 보관되며, 무엇이 버려지는지 정확히 나와 있습니다.

시작하기

  1. 확장 프로그램을 설치합니다. Chrome 웹 스토어 등록 전까지는 소스에서 설치합니다.
  2. Monid 또는 treg에서 API 키를 만듭니다.
  3. 확장 프로그램 설정에 붙여 넣고 Gmail에서 메일을 엽니다.

데이터가 어떻게 처리되는지는 개인정보 처리방침에서 확인하세요. Clearbit에서 오셨나요? Clearbit Connect 대안 페이지를 보세요.

SenderFinder는 AGPL-3.0 라이선스로 공개된 오픈 소스 소프트웨어입니다.

Gmail, Outlook, LinkedIn, Chrome은 각 소유자의 상표입니다.

이 웹사이트는 방문 횟수를 집계하기 위해 개인정보 친화적인 분석 도구를 사용할 수 있습니다. SenderFinder 확장 프로그램은 이와 별개이며, 설정에서 끄지 않는 한 하루에 한 번 익명 사용 통계 요약을 보냅니다. 개인정보
