Clearbit Connect는 사라졌습니다. 오픈 소스 대안은 여기 있습니다.

SenderFinder는 Gmail 안에서 누가 메일을 보냈는지 보여 줍니다. 오픈 소스이고 직접 발급한 API 키로 동작하며 계정이 필요 없습니다.

Clearbit Connect란 무엇이었나

Clearbit Connect는 Gmail과 Outlook용 무료 확장 프로그램이었습니다. 메일을 읽을 때 발신자의 직책과 회사 같은 정보를 보여 주었습니다.

HubSpot이 Clearbit을 인수한 뒤 Clearbit Connect는 서비스가 종료되었습니다. 2025년 4월 30일부터 작동하지 않습니다.

SenderFinder가 하는 일

Gmail에서 메일을 엽니다. 브라우저 사이드 패널에 그 사람의 LinkedIn 프로필이 표시됩니다. 이름, 한 줄 소개, 회사, 위치, 프로필 링크까지. 스레드의 다른 사람은 아래에 나열되며 클릭 한 번으로 조회할 수 있습니다.

웹 Outlook은 가능한 범위 내에서 지원합니다.

무엇이 다른가

  • 오픈 소스. 코드는 AGPL-3.0 라이선스로 GitHub에 있습니다. 무엇을 하는지 직접 확인할 수 있습니다.
  • 직접 발급한 키. 확장 프로그램은 설정에 붙여 넣은 키로 브라우저에서 데이터 제공업체를 직접 호출합니다. 지원: Monid와 treg, 선택적 대체 수단으로 Firecrawl.
  • 가입 불필요. 조회는 브라우저에서 설정한 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다. 익명 일일 사용 통계는 기본적으로 켜져 있고 설정에서 끌 수 있습니다.
  • CRM에 묶이지 않습니다. 결과는 브라우저에 남습니다. 기록을 JSON이나 CSV로 내보내 원하는 곳에 가져갈 수 있습니다.
  • 예측 가능한 비용. 가장 저렴한 곳을 먼저 시도하고, 처음 일치하는 곳에서 연쇄를 멈춥니다. 조회당 상한과 일일 상한이 지출을 관리합니다. 결과는 캐시되므로 같은 주소로 두 번 결제하는 일은 없습니다.

솔직한 한계

  • 제공업체 키가 필요합니다. Monid 또는 treg 키 하나면 시작할 수 있지만 직접 발급해야 합니다.
  • 조회마다 무료는 아닙니다. 조회 성공 시 보통 $0.0005에서 $0.03 사이이며, 대개 1센트를 크게 밑돕니다. 대부분의 제공업체는 실패해도 무료입니다.
  • Firefox는 아직 없습니다. Chrome에서 동작합니다. Apple Mail이나 데스크톱용 Outlook 같은 데스크톱 메일 앱은 지원하지 않습니다.
  • 결과는 제공업체의 범위에 달려 있습니다. 찾지 못하는 사람도 있습니다. 제공업체가 준 이름이 메일에 적힌 이름과 다르면 결과에 “불확실”이 표시되고 두 이름이 함께 나옵니다.

데이터가 가는 곳

Clearbit Connect는 호스팅 서비스였습니다. 조회는 Clearbit 서버에서 실행되었고 Clearbit 계정으로 로그인해야 했습니다.

SenderFinder는 오픈소스 Chrome 확장 프로그램입니다. 조회 요청은 브라우저에서 설정한 데이터 제공업체로 직접 전송되며, 조회 경로에 SenderFinder 서버가 없습니다. 별도의 통계 서비스가 익명 일일 요약을 하나 받는데, 기본적으로 켜져 있고 설정 페이지에서 끌 수 있습니다. 통계의 데이터 관리자는 astonysh/SenderFinder 관리자인 Tony Li입니다. 개인정보 관련 요청은 tony@senderfinder.com으로 보내 주세요.

개인정보 처리방침에 무엇이 전송되고, 무엇이 보관되며, 무엇이 버려지는지 정확히 나와 있습니다.

전환은 몇 분이면 됩니다

  1. Chrome 웹 스토어 또는 Microsoft Edge 추가 기능에서 확장 프로그램을 설치하세요.
  2. Monid 또는 treg에서 API 키를 만듭니다.
  3. 확장 프로그램 설정에 붙여 넣고 Gmail에서 메일을 엽니다.

데이터가 궁금하면 개인정보 처리방침을 읽어 보세요. 예전 도구를 찾고 있다면 Rapportive 대안 페이지를 보세요.
