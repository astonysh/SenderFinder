プライバシー

SenderFinder は開いているメールの送信者と参加者を読み取り、本文をローカルでスキャンして LinkedIn プロフィールのリンクを探します。LinkedIn 機能を有効にすると、ご自身の LinkedIn セッションを使って、つながりの度合い、保留中の招待、プロフィール写真、関連する会社リンクを読み取ります。Connect 補助機能は「Add a note」を 1 回クリックし、確認できるようメモを入力します。検索項目は設定したプロバイダーへ直接送信されます。匿名の利用統計は既定でオンで、設定のスイッチを 1 つオフにすると停止します。 許可すると、LinkedIn から現在の役職、会社、所在地も補完できます。

30 秒でわかる

  • 検索リクエストはブラウザーから設定したプロバイダーへ直接送信されます。検索経路に SenderFinder のサーバーはありません。
  • キー、キャッシュ、履歴は、拡張機能のストレージとお使いのブラウザの IndexedDB に、この端末内で保存されます。書き出すことも、ワンクリックで消去することもできます。
  • プロバイダーが受け取るのは、検索するアドレス、メールヘッダーの表示名、会社ドメインです。それ以外はありません。
  • メール本文がブラウザの外に出ることはありません。署名のスキャンはローカルで実行されます。
  • 利用統計は既定でオンです。1 日 1 回、回数、結果、費用、バージョン、言語にランダムなインストール ID を加えた匿名の概要が、プロジェクトの統計サービスへ送信されます。設定のスイッチを 1 つオフにすると停止し、インストール ID は削除されます。メールアドレス、氏名、ドメイン、プロフィール項目、キー、メール本文は一切含まれません。
  • 設定するプロバイダーと検索対象はご自身で選べます。統計を停止し、LinkedIn 権限を取り消し、ローカルデータをエクスポートまたは削除できます。各機能の読み取りと送信先は以下の説明をご覧ください。

SenderFinder の運営者

SenderFinder はオープンソースの Chrome 拡張機能です。検索リクエストはブラウザーから設定したデータプロバイダーへ直接送られ、検索経路に SenderFinder のサーバーはありません。別の統計サービスが匿名の日次概要を 1 件受け取りますが、これは既定でオンで、設定ページからオフにできます。統計データの管理者は astonysh/SenderFinder のメンテナー Tony Li です。プライバシーに関する連絡先：tony@senderfinder.com。

拡張機能が読み取るもの、保存するもの

ウェブ版の Gmail または Outlook で、拡張機能は開いているメッセージの送信者と参加者を読み取ります。LinkedIn プロフィールの URL（たとえば署名内のもの）を見つけるため、メッセージ本文をローカルでスキャンします。本文は保存されず、送信もされません。検索履歴、結果、設定、プロバイダーのキーは、拡張機能またはブラウザ内にローカル保存されます。キャッシュされた結果は既定で 90 日後に失効し、上限は 5,000 件です。設定から書き出すか削除できます。

データプロバイダーが受け取るもの

検索を実行すると、対象の人物のメールアドレス、表示名、会社ドメインが、そのプロバイダーの API キーを使って、設定したプロバイダーへ直接送信されます。プロバイダーの中にはアグリゲーターもあり、リクエストを提携先のサービスへ転送することがあります。その場合は各サービスの利用規約とプライバシーポリシーが適用されます。SenderFinder は検索したアドレスもプロバイダーの結果も受け取りません。プロバイダーが返した業務に関するプロフィール項目はローカルに保存され、電話番号と個人用メールアドレスは破棄されます。

匿名の利用統計

利用統計は既定でオンです。1 日 1 回、拡張機能は前日の概要を 1 件当方の Cloudflare Worker に送信し、Worker がそれを Cloudflare D1 に保存します。概要に含まれるのは、日付、拡張機能のバージョン、インターフェースの言語、検索の合計回数と結果、プロバイダーのステップ別の回数、メールクライアント別の合計、四捨五入した費用、ランダムなインストール ID です。この ID はインストールを識別するもので、個人を識別するものではありません。設定ページのスイッチを 1 つオフにすると概要の送信は停止し、インストール ID と未送信のデータが削除されます。隣のプレビューボタンには、送信される内容がそのまま表示されます。

概要には、メールアドレス、氏名、会社ドメイン、LinkedIn の URL、プロフィール項目、プロバイダーのキー、メッセージの本文は含まれません。送信内容は設定で正確にプレビューできます。統計をオフにすると、以降の送信は停止し、ローカルのインストール ID と未送信の概要は削除されます。過去に受信した概要の削除を希望する場合は、プレビューに表示されるインストール ID を添えて tony@senderfinder.com までご連絡ください。

LinkedIn

LinkedIn 機能を有効にすると、拡張機能は初回利用時に任意の linkedin.com 権限を求めます。この権限は設定からいつでも取り消せ、拡張機能が自ら開いたタブにのみ適用されます。許可すると、拡張機能はご自身の LinkedIn セッションを使って、表示中のプロフィールのつながりの度合い、保留中の招待、プロフィール写真、関連する会社リンクを取得します。認証 Cookie の JSESSIONID は、これらのリクエストの CSRF 値としてローカルで読み取ります。Cookie は LinkedIn にのみ送信され、SenderFinder や情報補完プロバイダーへ送られることはありません。結果はお使いの端末にキャッシュされ、どこにも送信されません。Connect を選ぶと、拡張機能は選択したプロフィールを開き、招待ダイアログで「Add a note」を 1 回クリックして、編集可能なテンプレートを入力します。Connect と Send をクリックすることはありません。

ご自身の選択と Chrome ウェブストアのポリシー

どのデータプロバイダーと API キーを設定するか、誰を検索するかはご自身で選べます。キーの削除、統計のオフ、LinkedIn 権限の取り消し、ローカル履歴の書き出しや消去、拡張機能のアンインストールも可能です。SenderFinder がメールボックスのデータを使うのは、ご自身が求めた検索を表示し実行するためだけです。メール本文は、LinkedIn プロフィールへのリンクを見つけるためだけにローカルで処理され、広告には使われず、SenderFinder やプロバイダーへ送信されることもありません。

Cookie とローカルストレージ

この節は SenderFinder のウェブサイトについて説明し、拡張機能についてではありません。拡張機能は匿名の利用統計の概要を 1 日 1 回送信します。これは既定でオンで、拡張機能の設定からオフにできます。ウェブサイト自体は、以下に記載するブラウザーのローカルストレージを使用します。

現時点で、このウェブサイトは Cookie を設定していません。お使いのブラウザの localStorage にある 2 つの項目を使いますが、どちらもご自身が求めたときだけ使われます。el-theme はヘッダーで選んだライトまたはダークの設定を、sf-notice はページ下部のお知らせを閉じたことを記憶します。どちらもどこかへ送信されることはなく、ブラウザでサイトデータを消去すれば両方とも削除されます。

ウェブサイトのアクセス解析。このサイトにアクセス解析を追加する場合は、この段落でツール名、何を数えるか、オプトアウトの方法を示し、法律で求められる場合にはページ下部のお知らせで同意を求めます。それまでは、第三者のアクセス解析スクリプト、フォント、画像をここで読み込むことはありません。

このサイトは Cloudflare Workers Static Assets でホストされています。Cloudflare は、ページを配信し、サービスを不正利用から守るために、IP アドレスなどリクエストの技術的なデータを、同社自身のプライバシー条件に基づいて処理します。

このサイトでは、Cloudflare Web Analytics、Zaraz および同様の挿入機能を有効にしていません。変更がある場合は、この節もあわせて変更します。

このウェブサイトと連絡先

このウェブサイトは静的で、Cookie もアクセス解析も使用しません。ご質問やプライバシーに関するご依頼は、tony@senderfinder.com までご連絡いただくか、GitHub で issue を作成してください。
