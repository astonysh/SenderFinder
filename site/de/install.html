SenderFinder installieren

Den Eintrag im Chrome Web Store gibt es noch nicht, deshalb lädst du die Erweiterung aus dem Quellcode. Zwei Minuten, einmal pro Browser.

Du brauchst Chrome, Edge oder einen anderen Chromium-Browser auf einem Desktop-Rechner; in den mobilen Apps lassen sich keine Erweiterungen hinzufügen. Die Screenshots sind auf Englisch, die Erweiterung selbst folgt der Sprache deines Browsers.

ZIP herunterladen Repository öffnen

Datenschutz auf einen Blick

  • Der Schlüssel, den du einfügst, liegt im eigenen Speicher der Erweiterung auf diesem Gerät und wird nur an die API des jeweiligen Anbieters gesendet, zusammen mit den Abfragen, die du ausführst.
  • Abfragen gehen direkt von deinem Browser an den Anbieter, den du konfigurierst – kein SenderFinder-Server im Abfrageweg. Anonyme tägliche Nutzungszählung ist standardmäßig an und lässt sich in den Einstellungen abschalten.
  • Entferne den Schlüssel jederzeit in den Einstellungen – ohne Schlüssel kann keine kostenpflichtige Abfrage laufen – oder deinstalliere die Erweiterung, was ihren Speicher löscht.

Fünf Schritte

  1. 1

    Code holen

    Lade das Repository als ZIP von GitHub herunter („Code“ → „Download ZIP“) und entpacke es, oder klone es, wenn du git hast:
    git clone https://github.com/astonysh/SenderFinder.git

  2. 2

    In Chrome laden

    Öffne chrome://extensions in einem neuen Tab. Schalte den Entwicklermodus ein (oben rechts), klicke auf Entpackte Erweiterung laden und wähle den Ordner extension/ im Repository – den Ordner, der manifest.json enthält, nicht das Stammverzeichnis des Repositories.

  3. 3

    Einen Schlüssel holen und einfügen

    Die Einstellungsseite öffnet sich nach der Installation von selbst. Erstelle einen Schlüssel bei Monid (Hunter, Apollo, ContactOut) oder treg (BlitzAPI, QuickEnrich, Village); Firecrawl ist optional. Ein Schlüssel reicht. Füge ihn unter „Anbieter-Keys“ ein.

  4. 4

    Auf „Keys testen (kostenlos)“ klicken

    Die Prüfung ist kostenlos: Sie prüft den Schlüssel und liest die Preisliste des Anbieters. Es wird nichts nachgeschlagen und nichts ausgegeben. Du willst „gültig“ neben deinem Schlüssel sehen.

  5. 5

    Gmail öffnen und einmal auf das Symbol in der Symbolleiste klicken

    Öffne eine beliebige Nachricht in Gmail und klicke dann auf das SenderFinder-Symbol in der Symbolleiste von Chrome. Wenn du es nicht siehst, klicke auf das Puzzleteil-Symbol und hefte SenderFinder zuerst an. Die Seitenleiste öffnet sich und bleibt in diesem Tab offen; von da an folgt sie der E-Mail, die du liest.

Sobald der Eintrag im Chrome Web Store online ist, wird diese Seite eine Installation mit einem Klick; bis dahin sind die Schritte oben der einzige Weg.

Wenn etwas nicht funktioniert

Die Seitenleiste öffnet sich nicht

Hefte SenderFinder zuerst an: Puzzleteil-Symbol in der Symbolleiste → anheften. Klicke dann einmal auf sein Symbol, während ein Gmail-Tab offen ist. Die Seitenleiste öffnet sich nie von selbst, und sie gilt pro Tab.

Die Seitenleiste sagt „Kein Key hinterlegt“

Füge in den Einstellungen der Erweiterung einen Schlüssel ein. Einer reicht: Schritte, deren Anbieter keinen Schlüssel hat, werden ohne Fehler übersprungen.

In Outlook passiert nichts

Outlook im Web läuft nach bestem Bemühen, und sein Markup ändert sich oft. Wenn die kleine Markierung neben dem Absender nicht erscheint, öffne ein Issue mit dem HTML der Absenderzeile.

Eine Adresse mit gmail.com oder info@ wird nicht nachgeschlagen

Private Postfach-Domains und Funktionsadressen werden standardmäßig übersprungen, weil sie selten zu einem Profil führen. Für sie hat die Seitenleiste die Schaltfläche „Trotzdem nachschlagen“.

Es hat heute aufgehört, Personen nachzuschlagen

Entweder wurde das Tagesbudget ($2 als Standard) oder das Limit für automatische Abfragen (30 pro Tag) erreicht. Beides ist in den Einstellungen änderbar; die Zähler beginnen am nächsten Tag neu.

Wie aktualisiere ich es später

Lege die neuen Dateien in denselben Ordner und klicke auf der Karte in chrome://extensions auf den Pfeil zum Neuladen. Die ID der Erweiterung ist im Manifest festgelegt, Schlüssel, Cache und Verlauf bleiben also erhalten.

Wie es weitergeht

Lies wie es funktioniert, sieh dir an, was eine Abfrage kostet, oder berechne dein eigenes Volumen im Kostenrechner. Fragen zu Daten beantwortet die Datenschutzerklärung.

SenderFinder

Kein SenderFinder-Server im Abfrageweg. Deine Schlüssel und dein Verlauf bleiben in deinem Browser.
