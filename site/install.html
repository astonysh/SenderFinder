Install SenderFinder

Install SenderFinder from the Chrome Web Store or Microsoft Edge Add-ons, then follow the setup steps below.

You need Chrome, Edge or another Chromium browser on a desktop; extensions can't be added to the mobile apps. The screenshots are in English, the extension itself follows your browser language.

Add to Chrome Add to Microsoft Edge Open the repository

Privacy at a glance

  • The key you paste is stored in the extension's own storage on this device and is sent only to that provider's API, with the lookups you run.
  • Lookups go directly from your browser to the provider you configure — no SenderFinder server in the lookup path. Anonymous daily usage counts are on by default and can be switched off in settings.
  • Remove the key in settings at any time — without a key no paid lookup can run — or uninstall the extension, which deletes its storage.

Set up SenderFinder in three steps

  1. 1

    Get one key and paste it

    The settings page opens by itself after installation. Create a key at Monid (Hunter, Apollo, ContactOut) or treg (BlitzAPI, QuickEnrich, Village); Firecrawl is optional. One key is enough. Paste it under “Provider keys”.

  2. 2

    Press “Test keys (free)”

    The check is free: it verifies the key and reads the provider's price list. Nothing is looked up and nothing is spent. You want “valid” next to your key.

  3. 3

    Open Gmail and click the toolbar icon once

    Open any message in Gmail, then click the SenderFinder icon in Chrome's toolbar. If you can't see it, click the puzzle-piece icon and pin SenderFinder first. The side panel opens and stays open in that tab; from then on it follows the email you read.

Chrome and Edge store installs update automatically.

If something doesn't work

The side panel doesn't open

Pin SenderFinder first: puzzle-piece icon in the toolbar → pin. Then click its icon once while a Gmail tab is open. The panel never opens by itself, and it is per tab.

The panel says “No key set”

Paste one key in the extension settings. One is enough: the steps whose provider has no key are skipped without an error.

Nothing happens in Outlook

Outlook on the web is best-effort and its markup changes often. If the small mark next to the sender doesn't appear, open an issue with the sender line's HTML.

A gmail.com or info@ address isn't looked up

Personal mailbox domains and role addresses are skipped by default, because they rarely lead to a profile. The panel has a “Look up anyway” button for those.

It stopped looking people up today

Either the daily cap ($2 by default) or the automatic-lookup limit (30 per day) was reached. Both are adjustable in settings; the counters reset the next day.
