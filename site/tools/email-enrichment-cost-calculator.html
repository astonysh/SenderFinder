How to calculate email enrichment waterfall cost

A waterfall sends an address to the first provider, stops when a usable match is found and forwards only unresolved addresses to later steps. Cost therefore depends on both price and position: a more expensive provider near the end may receive only a small share of the original volume.

This calculator applies each step's conditional match rate to the contacts that reach it. Successful-match billing is charged on matches; call-based billing is charged on every address reaching that step. The provider table makes that arithmetic visible instead of hiding it behind a single total.

What the estimates include

  • The published provider order, catalogue prices and benchmark step hit rates used by SenderFinder's current cost model.
  • A configurable share of contacts that are already known or cached and therefore avoid a paid lookup.
  • Expected values for planning. Individual batches are discrete and can differ substantially, especially at low volume.
  • Matches with the expected name under the benchmark's validation rules; a returned profile is not automatically counted as a correct match.

Compare cost per match, not only cost per API call

A cheap call with a low match rate can be useful early in a waterfall because every successful answer prevents a later call. A higher-priced step can still improve total coverage when it runs only on the unresolved remainder. Compare expected cost per matching profile alongside the unresolved count before removing a provider.

Use the same waterfall inside the inbox

SenderFinder adds a sidebar to Gmail and Outlook. When an email address is not already known, the extension can try the configured enrichment steps in sequence, cache the outcome in the browser and show the LinkedIn profile beside the message.

The calculator does not call any provider or require an API key. It is a planning companion for deciding which keys to configure in the extension.

Email enrichment cost calculator FAQ

What the forecast means and where its limits are.

Is this a vendor price quote?

No. It is an independent planning estimate using catalogue prices and benchmark rates documented by SenderFinder. Confirm current prices, credit rules and limits with each provider.

What is a waterfall enrichment strategy?

It tries providers in sequence and stops after a usable match. Later providers receive only the contacts that earlier steps could not resolve.

Why can my real hit rate differ?

Match rates depend on geography, company type, email quality, provider coverage and validation rules. A 50-address benchmark cannot represent every audience.

Does the calculator upload my volume or provider choice?

No. The calculations run in your browser and the page makes no enrichment API request.
