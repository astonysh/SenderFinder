See who's emailing you.

Open an email in Gmail and the browser's side panel shows the sender's LinkedIn profile: name, role, company, location. Open source. Your own API key, no account, no server in between.

How it works

Three steps. No signup anywhere except with the data provider you choose.

  1. Install the extension

    Add it to Chrome. Until the Web Store listing is live, install it from source in a minute.

    Install from source

  2. Get one API key

    Create a key at Monid or treg. One of the two is enough to start.

  3. Paste it in settings

    Open the extension's settings and paste the key. Then open any email in Gmail.

What you see

  • A side panel with name, headline, company, location and a link to the profile. The email itself only gets a small "in" mark next to the sender.
  • Other people in the thread (other senders, To, Cc) listed in the panel. They are looked up only when you click them.
  • An "uncertain" mark when the provider's name doesn't match the name in the email header. Both names are shown.

Where it works

  • Gmail on the web.
  • Outlook on the web, on a best-effort basis.
  • Not supported: desktop mail apps such as Apple Mail or Outlook for desktop, and Firefox (not yet).

Cheapest first. Then it stops.

You pay the data providers directly, with your own key. The extension tries the free option first, then paid providers from cheapest to most expensive, and stops at the first match.

  1. Email signature scan Free. If the signature contains a linkedin.com/in link, that's the answer.
  2. Cheapest paid provider The current catalog price is read first. If it's above your per-lookup cap, the step is skipped.
  3. Next provider, only on a miss Misses on most providers are free.
  4. Match found, chain stops The result is cached in your browser. The same address never costs money twice.

Only the sender, automatically

Only the sender of the email you open is looked up on its own. You set a daily limit on automatic lookups. Everyone else in the thread waits for a click.

No money spent on dead ends

Personal mailbox domains (gmail.com, outlook.com, qq.com and similar) and role addresses (info@, support@ and similar) are skipped by default. A button lets you look them up anyway.

Supported providers

The extension calls these services directly from your browser, using keys you paste into its settings.

Monid

An API aggregator. One key gives access to Hunter.io, Apollo and ContactOut.

treg

An aggregator for BlitzAPI, QuickEnrich and Village.

Firecrawl (optional)

An optional fallback, for Data Legion.

Your order, your limits

In settings you can switch providers on or off, change their order, and set both caps. Settings also show your history and spending.

There is no "us" in the middle

  • No account, no signup, no server in the lookup path. The only thing sent to us is a daily anonymous usage count, which you can switch off.
  • Data flows only between your browser and the providers you configured.
  • Only professional fields are kept: name, title, company, location and LinkedIn URL.
  • Phone numbers and personal emails returned by providers are discarded.
  • History and cache live in your browser's IndexedDB.
  • Export everything as JSON or CSV, or wipe it, from the settings page.

Questions

Is it free?

The extension is free and open source under the AGPL-3.0 license. Lookups are paid to the data provider you choose, with your own key. A successful lookup usually costs well under a cent, and the caps keep spending predictable.

Do I need an account?

Not with us. There is no account and no server in the lookup path. You only need a key from a data provider.

Which key should I get?

One key from either Monid or treg is enough to start. Adding both, and optionally Firecrawl, gives the waterfall more places to look.

How do I keep costs under control?

There is a per-lookup cap (default $0.05) and a daily cap (default $2). Only the sender of the opened email is looked up automatically, with a daily limit you set. Results are cached, so the same address is never paid for twice.

What if it shows the wrong person?

If the name from the provider doesn't match the display name in the email header, the result is marked "uncertain" and shows both names, so you can judge for yourself.

Why is a gmail.com sender not looked up?

Personal mailbox domains and role addresses like info@ rarely match a profile, so they are skipped by default to save money. Click the button in the panel to look them up anyway.

Does it work in Outlook, Apple Mail or Firefox?

Outlook on the web is supported on a best-effort basis. Desktop mail apps such as Apple Mail and Outlook for desktop are not supported. Firefox is not supported yet.

Where is my data stored?

On your device. Keys are kept in the extension's storage. History and cache are kept in your browser's IndexedDB. You can export or wipe them from the settings page. See the privacy statement.

Is this a replacement for Rapportive or Clearbit Connect?

It does the job they used to do: show who is behind an email address. Read more about the Clearbit Connect alternative and the Rapportive alternative.
