Rapportive 已经没了。思路还在。

SenderFinder 把 Rapportive 里最简单的那部分带回来了：在 Gmail 打开一封邮件，就能看到是谁发的。开源，用你自己的 API key，没有账号。

添加到 Chrome 添加到 Microsoft Edge 工作原理

Rapportive 是什么

Rapportive 是一个 Gmail 插件，会在邮件旁边显示你正在通信的那个人的 LinkedIn 资料。LinkedIn 在 2012 年收购了它，后来把它关停了。

SenderFinder 做什么

你在 Gmail 里打开一封邮件时，浏览器侧边栏会显示发件人的姓名、职位、公司、地点，以及他的 LinkedIn 资料链接。线程里的其他人（其他发件人、收件人、抄送）列在下面，只有你点他们时才查询。邮件本身只在发件人旁边多一个小标记。

Outlook 网页版为尽力支持。

有哪些不同

  • 开源。采用 AGPL-3.0 许可证，代码在 GitHub 上。没有哪家公司能替你把它关掉。
  • 用你自己的 key。资料来自你自己选的数据供应商：Monid 或 treg，Firecrawl 作为可选兜底。插件从你的浏览器直接调用它们。
  • 无需注册。查询请求从浏览器直接发送给你配置的数据供应商；查询路径上没有 SenderFinder 服务器。匿名每日使用统计默认开启，可以在设置里关闭。
  • 不被 CRM 绑住。历史留在你的浏览器里。想什么时候导出成 JSON 或 CSV 都行。
  • 姓名核对。如果供应商给的姓名和邮件里的显示名对不上，结果会标为「不确定」并显示两个名字。

说清楚的局限

  • 你需要一个供应商 key。Monid 或 treg 的一把 key 就够开始用了。
  • 查询要花一点钱。一次成功的查询通常花 $0.0005 到 $0.03，一般远低于一美分。大多数供应商没命中不收费，结果会缓存，同一个地址不会花第二次钱。
  • 花费有你自己设的上限。有单次上限（默认 $0.05）和每天上限（默认 $2）。只有你打开的这封邮件的发件人会被自动查询。
  • 还没有 Firefox。它跑在 Chrome 里。桌面邮件客户端不支持。
  • 覆盖范围因人而异。不是每个人都能查到，gmail.com 这类个人邮箱地址默认跳过。侧边栏里有按钮，可以仍然查询。

数据去了哪里

Rapportive 也是一个托管服务：资料查询在它的服务器上运行，和你的 Rapportive 账号绑在一起。

SenderFinder 是开源 Chrome 插件。查询请求从浏览器直接发送给你配置的数据供应商；查询路径上没有 SenderFinder 服务器。另有一个独立的统计服务，会接收一份匿名每日汇总，默认开启，可以在设置页关闭。该统计数据的控制者是 astonysh/SenderFinder 仓库的维护者 Tony Li。隐私请求请联系 tony@senderfinder.com。

在隐私说明里逐条写明了什么会发送、什么会保存、什么会被丢弃。

开始用

  1. 从 Chrome 应用商店或 Microsoft Edge 扩展商店安装插件。
  2. 在 Monid 或 treg 创建一个 API key。
  3. 把它填进插件设置，然后在 Gmail 里打开一封邮件。

数据怎么处理，见隐私说明。从 Clearbit 过来的？看Clearbit Connect 替代方案页面。
