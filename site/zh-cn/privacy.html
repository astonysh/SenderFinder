SenderFinder 会读取当前邮件的发件人和参与者，并在本机扫描正文以查找 LinkedIn 资料链接。你开启 LinkedIn 功能后，插件会用你自己的 LinkedIn 登录会话读取关系度、是否有待处理的邀请、资料头像和关联的公司链接。「加好友」辅助会在邀请对话框里点一次「Add a note」并填入备注，由你自己检查。查询字段会直接发送给你配置的数据供应商。匿名使用统计默认开启，在设置里一个开关就能关掉。

SenderFinder 的运营者

SenderFinder 是开源 Chrome 插件。查询请求从浏览器直接发送给你配置的数据供应商；查询路径上没有 SenderFinder 服务器。另有一个独立的统计服务，会接收一份匿名每日汇总，默认开启，可以在设置页关闭。该统计数据的控制者是 astonysh/SenderFinder 仓库的维护者 Tony Li。隐私请求请联系 tony@senderfinder.com。

插件会读取和保存什么

在 Gmail 或 Outlook 网页版中，插件会读取当前邮件的发件人和参与者，并在本机扫描正文以查找 LinkedIn 资料链接（例如邮件签名中的链接）。正文不会被保存或传输。查询历史、结果、设置和供应商 key 保存在插件或浏览器的本地存储中。缓存默认 90 天后过期，最多保存 5,000 条；你可以在设置中导出或删除这些数据。

数据供应商会收到什么

执行查询时，被查询者的邮箱地址、显示名和公司域名会使用对应的 API key，直接发送给你配置的数据供应商。部分供应商是聚合服务，可能会把请求转发给其列出的下游服务；应以这些服务各自的条款和隐私政策为准。SenderFinder 不会收到查询地址或供应商返回结果。供应商返回的职业资料保存在本机；电话号码和个人邮箱会被丢弃。

匿名使用统计

使用统计默认开启。插件每天向我们的 Cloudflare Worker 发送一次前一天的汇总，Worker 将其存入 Cloudflare D1。汇总包含日期、插件版本、界面语言、查询次数和结果、各供应商步骤的计数、邮箱客户端的计数、取整后的花费，以及随机生成的安装 ID。该 ID 用于区分安装，不代表某个人。在设置页关掉这个开关，就会停止发送，并删除安装 ID 和尚未发送的数据；旁边的预览按钮会显示将要发送的确切内容。

汇总不包含邮箱地址、姓名、公司域名、LinkedIn 链接、资料字段、供应商 key 或邮件正文。你可以在设置中预览将要发送的确切内容。关闭统计后，之后不会再发送，并会删除本机安装 ID 和尚未发送的汇总。如需删除服务器已收到的历史汇总，请联系 tony@senderfinder.com，并提供预览中显示的安装 ID。

LinkedIn

你开启某个 LinkedIn 功能时，插件会在首次使用时请求可选的 linkedin.com 权限；你随时可以在设置里撤销，而且该权限只作用于插件自己打开的标签页。有了它，插件会用你自己的 LinkedIn 登录会话，请求你正在查看的那个资料的关系度、是否有待处理的邀请、资料头像以及关联的公司链接。插件在本机读取 JSESSIONID 认证 Cookie 作为这些请求的 CSRF 值；该 Cookie 只发送给 LinkedIn，绝不发给 SenderFinder 或资料查询供应商。结果缓存在你的设备上，不会发给任何人。你选择「加好友」时，插件会打开所选资料，在邀请对话框里点一次「Add a note」并填入你的可编辑模板。插件不会替你点击 Connect 或 Send。

你的选择与 Chrome 应用商店政策

你可以自行选择要配置的数据供应商和 API key，也可以决定查询哪些人。你可以删除 key、关闭使用统计、撤销 LinkedIn 权限、导出或清空本地历史，或卸载插件。SenderFinder 只会为展示资料和执行你发起的查询而使用邮箱数据。邮件正文只在本机处理，用于寻找 LinkedIn 资料链接；不会用于广告，也不会发给 SenderFinder 或供应商。

Cookie 与本地存储

本节说明的是 SenderFinder 网站，而不是插件。插件每天发送一份匿名使用汇总，默认开启，可在插件设置里关闭。网站本身使用的浏览器本地存储见下文。

目前本站不设置 Cookie。浏览器 localStorage 里有两项，都是因为你主动用过才存在的：el-theme 记住你在页头选的浅色或深色，sf-notice 记住你关掉了页面底部的提示。它们从不发往任何地方，清除浏览器里的站点数据就会一并删除。

网站访问统计。如果以后给本站加上访问统计，这一段会写明用的是哪个工具、统计什么、怎么退出，页面底部的提示也会在法律要求时征求同意。在那之前，这里不加载任何第三方的统计脚本、字体或图片。

本站托管在 Cloudflare Workers Static Assets 上。Cloudflare 会按它自己的隐私条款处理请求的技术数据（例如 IP 地址），用来把页面送达并防止滥用。

本站没有开启 Cloudflare Web Analytics、Zaraz 等注入功能。如果以后开启，这一节也会跟着改。

本网站与联系方式

本站是静态页面，不设置 Cookie，也没有访问统计。隐私方面的问题或请求，请写信到 tony@senderfinder.com，或在 GitHub 上开一个 issue。
