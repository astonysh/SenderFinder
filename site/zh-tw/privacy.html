隱私權

誰經營 SenderFinder

SenderFinder 是開放原始碼的 Chrome 擴充功能。查詢請求會從你的瀏覽器直接傳送給你設定的資料供應商；查詢路徑上沒有 SenderFinder 伺服器。另有一項獨立的統計服務會收到每天一份匿名摘要，預設開啟，可在設定頁關閉。這些統計資料的控管者是 GitHub 專案 astonysh/SenderFinder 維護者 Tony Li。隱私權相關請求請聯絡 tony@senderfinder.com。

擴充功能會讀取和保存什麼

在 Gmail 或網頁版 Outlook 中，擴充功能會讀取目前開啟郵件的寄件者和參與者。它會在本機掃描郵件本文，找出 LinkedIn 個人檔案網址，例如簽名檔裡的連結。郵件本文不會被儲存，也不會被傳送。查詢歷史記錄、結果、設定和供應商 key 都存放在本機的擴充功能或瀏覽器中。快取結果預設 90 天後過期，上限 5,000 筆；你可以在設定裡匯出或刪除。

資料供應商會收到什麼

查詢執行時，所選對象的電子郵件地址、顯示名稱和公司網域，會使用該供應商的 API key 直接送到你設定的供應商。有些供應商是聚合服務，可能會把請求轉送給它們列出的下游服務；適用它們自己的條款和隱私權政策。SenderFinder 不會收到查詢的地址或供應商回傳的結果。供應商回傳的職業相關個人檔案欄位會保存在本機；電話號碼和個人電子郵件地址則會丟棄。

匿名使用統計

使用統計預設開啟。擴充功能每天會傳送一份前一天的摘要到我們的 Cloudflare Worker，由它儲存在 Cloudflare D1。摘要包含日期、擴充功能版本、介面語言、查詢總數與結果、各供應商步驟的次數、各郵件用戶端的次數、四捨五入後的花費，以及一組隨機安裝 ID。這個 ID 辨識的是一次安裝，不是一個人。在設定頁用一個開關就能關閉摘要，並刪除安裝 ID 和尚未傳送的資料；旁邊的預覽按鈕會顯示實際會傳送的內容。

摘要不含任何電子郵件地址、姓名、公司網域、LinkedIn 網址、個人檔案欄位、供應商 key 或郵件內容。你可以在設定裡預覽實際會傳送的內容。關閉統計後會停止之後的傳送，並刪除本機的安裝 ID 和尚未傳送的摘要。若要要求刪除先前已收到的摘要，請寫信到 tony@senderfinder.com，並附上預覽中顯示的安裝 ID。

LinkedIn

若你啟用 LinkedIn 功能，擴充功能會在首次使用時要求選用的 linkedin.com 權限；你隨時可以在設定中撤銷，而且它只適用於擴充功能自己開啟的分頁。取得權限後，擴充功能會用你自己的 LinkedIn 工作階段，針對你正在閱讀的個人檔案讀取關係程度、是否有待處理的邀請、個人檔案照片和關聯公司連結。它會在本機讀取 JSESSIONID 驗證 Cookie，作為這些請求的 CSRF 值；Cookie 只會傳給 LinkedIn，絕不會傳給 SenderFinder 或資料補全供應商。結果會快取在你的裝置上，不會傳送給任何人。你選擇「建立連結」時，擴充功能會開啟所選的個人檔案，並在邀請對話框中點一次「Add a note」，填入可編輯的範本。它絕不會點擊「建立連結」或「傳送」。

你的選擇與 Chrome Web Store 政策

要設定哪些資料供應商和 API key、要查詢哪些人，都由你決定。你可以移除 key、關閉統計、撤銷 LinkedIn 存取權、匯出或清除本機歷史記錄，或解除安裝擴充功能。SenderFinder 只會為了顯示和執行你要求的查詢而使用信箱資料。郵件本文只在本機處理，用來尋找 LinkedIn 個人檔案連結；不會用於廣告，也不會傳送給 SenderFinder 或供應商。

Cookie 與本機儲存空間

本節說明 SenderFinder 網站，而不是擴充功能。擴充功能每天會傳送一份匿名使用摘要，預設開啟，可在它的設定裡關閉。網站本身使用的瀏覽器本機儲存空間如下所述。

目前本站不設定 Cookie。瀏覽器 localStorage 裡有兩項，都是因為你主動用過才存在的：el-theme 記住你在頁首選的淺色或深色，sf-notice 記住你關掉了頁面底部的提示。它們從不傳往任何地方，清除瀏覽器裡的網站資料就會一併刪除。

網站瀏覽統計。如果以後給本站加上瀏覽統計，這一段會寫明用的是哪個工具、統計什麼、怎麼退出，頁面底部的提示也會在法律要求時徵求同意。在那之前，這裡不載入任何第三方的統計腳本、字型或圖片。

本站託管在 Cloudflare Workers Static Assets 上。Cloudflare 會依它自己的隱私條款處理請求的技術資料（例如 IP 位址），用來把頁面送達並防止濫用。

本站沒有開啟 Cloudflare Web Analytics、Zaraz 等注入功能。如果以後開啟，這一節也會跟著改。
