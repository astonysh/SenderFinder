隱私權

你的收件匣始終屬於你

查詢會從你的瀏覽器直接送到你選擇的供應商。以下說明哪些資料留在本機、哪些會送出，以及匿名統計包含哪些內容。

留在你的裝置上

  • 你的供應商 key，存在擴充功能自己的儲存空間
  • 快取與歷史記錄，在 IndexedDB 中（90 天、5,000 筆）
  • 設定、上限與自動查詢次數限制
  • 你讀過哪些郵件：這件事不會離開瀏覽器

送到你選擇的供應商

  • 你查詢的地址，連同你的 key
  • 郵件標頭中的顯示名稱
  • 公司網域，供 Apollo 步驟使用
  • 讀取該供應商目錄價格的請求

匿名使用統計

  • 預設開啟；在設定中用一個開關就能關閉
  • 每日彙總：次數、結果、花費、版本、語言
  • 隨機的安裝 ID，關閉統計時會一併刪除
  • 絕不包含地址、姓名、網域、key 或郵件內容

常見問題

簡短的回答

更長的答案在安裝指南和隱私權聲明中。

免費嗎？

是的。擴充功能免費，並以 AGPL-3.0 授權開放原始碼，不需要帳號，也不需要訂閱。付費查詢是選用的：由你選擇的資料供應商按次計費，直接記在你自己的 key 上，且不超出你設定的上限。郵件簽名檔掃描和快取都不收費。

需要帳號嗎？

不需要註冊。查詢會直接傳送給你設定的供應商；匿名每日使用統計會傳送到專案的統計服務，在設定裡用一個開關就能關閉。

該申請哪一組 key？

從 Monid 或 treg 取得一組 key 就足以開始。兩組都填，需要時再加上 Firecrawl，能讓瀑布流程有更多地方可查。安裝頁面有兩者的比較。

如何控制費用？

有單次查詢上限（預設 $0.05）和每日上限（預設 $2）。只有你開啟的郵件的寄件者會自動查詢，並受你設定的每日次數限制。結果會快取，同一個地址不會付兩次錢。費用試算可以估算特定用量要花多少。

如果顯示的人不對呢？

如果供應商回傳的姓名與郵件標頭的顯示名稱不符，結果會標上「不確定」並同時顯示兩個姓名，讓你自己判斷。

為什麼 gmail.com 的寄件者不被查詢？

個人信箱網域和 info@ 這類職務信箱很少對應到個人檔案，所以預設略過以節省費用。點面板上的按鈕就能仍要查詢。
